Neu / New:
- 30 Levels und sechs Schweizer Hintergrundwelten.
- 30 levels and six Swiss background worlds.
- DEVELOPMENT startet bei Level 3, 6, 9, 12, 15, 18, 21, 24, 27 oder 30.
- DEVELOPMENT starts at levels 3, 6, 9, 12, 15, 18, 21, 24, 27 or 30.
- Testläufe starten mit 3 Leben und 0 Punkten und ändern weder Highscore noch Freischaltungen.
- Test runs start with 3 lives and 0 score and change neither high score nor unlock progress.
- Nach WEITER folgt eine 1,8-Sekunden-Bereitschaftsphase. Der Schläger kann bereits bewegt werden.
- CONTINUE starts a 1.8-second ready phase. The paddle can already be moved.
- Der Schläger ist seitwärts rund 18 % schneller als der schnellste Ball und kann aufholen.
- Sideways paddle speed is about 18% faster than the fastest ball so it can catch up.

Reguläre Startlevel: Level 5/10/15/20/25/30 werden nach jeweils 10 normalen Abschlüssen freigeschaltet.
Regular starting levels: levels 5/10/15/20/25/30 unlock after 10 normal completions each.

DE/EN-Anleitung, Levelübersicht und Security-Testbericht sind als Word-Datei enthalten.
The package includes DE/EN instructions, level guide and security test report as a Word file.

Speicherhinweis / Storage note:
Fortschritt verwendet die bisherigen lokalen Speicherschlüssel. Derselbe Browser und Spielort sind erforderlich; ein anderer lokaler Dateipfad kann getrennten Speicher verwenden.
Progress reuses the existing local storage keys. Use the same browser and game location; a different local file path may use separate storage.
